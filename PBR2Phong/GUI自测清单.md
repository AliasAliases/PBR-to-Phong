## 0. 怎么打开

**两种都行，随便挑一种：**

| 方式 | 怎么做 | 前提 |
|---|---|---|
| **A. 打包版（发给别人就用这个）** | 双击 `dist\PBR2Phong\PBR2Phong.exe` | 什么都不用装 |
| **B. 源码版** | 双击工作区根目录的 `启动PBR2Phong.bat` | 要装 Python 3.11 + PySide6（缺了它自己会告诉你） |

⚠️ 打包版第一次运行，Windows 可能弹 **「未知发布者 / 已保护你的电脑」**（因为没买代码签名证书）→
点「**更多信息**」→「**仍要运行**」。这是正常现象，不是中毒。

## 0.5 五个页签分别是干什么的

| 页签 | 干什么 |
|---|---|
| **① 转换** | 工具路径（HLMV / VTFCmd）· 选择模式（模型 / 笔刷）· 导入素材 · 命名（决定材质路径）· 校验模型 |
| **② 预览 + 调参** | 左边两个大预览框（源素材 / 产出成品）· 右边参数列：预设 + 保存为预设 · 高光锐度 + 4 个档位 · 「其他参数」 |
| **③ 参数表 / 材质属性 / 自由键值** | 参数表（参数 / 当前值 / 来源）+ 恢复继承 · 表面类型 + 常用开关 · 自由键值 |
| **④ 导出** | 输出位置 / 部署目录 / 同名冲突提示 · 导出方式（直接写进游戏、开始转换）· 这次的结果 |
| **⑤ 关于** | 版本 / 许可 / 日志与配置目录 / 术语表 |

## 2. 一遍走完（大约 1 分钟）

| 步 | 你做什么 | 应该看到什么 |
|---|---|---|
| 1 | 把素材文件夹**拖进**「导入素材」的虚线框（或点「选择文件夹…」） | 虚线框下面那行变成 **「已识别 N 套素材」**；表格里每套一行，**说明**列写着认出了哪几张图（底色/粗糙度/…）。**拖错会弹框说人话**（见 §3.1） |
| 2 | 看「**命名（决定材质路径）**」区 | 有模型就选「我有编译好的模型」→ **把 `.mdl` 也直接拖到虚线框**（或点「浏览…」）→ 自动显示 **$cdmaterials 与材质名**；没有就选「还没有模型，我自己填」→ 填两栏 → 下面**实时**显示「将会写到：materials/…」 |
| 3 | （可选）点「**校验模型**」 | 弹框列出问题：产物位置对不对、贴图在不在、大小写一不一致、有没有 `no_material` |
| 4 | 到「**② 预览 + 调参**」选个预设（角色 / 武器 / 道具 / 玻璃） | 到「**③ 参数表 / 材质属性 / 自由键值**」看：**参数表**的「来源」列显示 `预设：XX`；每个参数下面都有一句**人话解释** |
| 4b | 顺手把**标签栏右上角**的「**English**」切成英文再切回来 | **整屏都变**（页签、按钮、参数解释），**底部状态栏那句也跟着变**，不应该残留中文 |
| 5 | 拖一下「**高光锐度**」滑杆（或点 4 个档位之一） | 拖的时候**只有右边数字跟手变**；**松手那一下**左边「产出成品」那张图会重算（看得出变了），第 ③ 页参数表对应行的来源从 `预设：XX` 变成 **`你改过`** |
| 5b | 看第 ② 页左边两个大框 | **左边 = 你导入的源素材底色**（标题写着素材名 + 尺寸）；**右边 = 当前参数下现算的成品**（默认「指数贴图」，下面能切「底色 / 法线」）。⚠️ 它是**内存里现算**的，不写盘、不调 VTFCmd |
| 5c | 拖「**粗糙度整体偏移**」和「**金属染色强度**」，再拖一下「**粗糙度映射**」那块里的控制点 | 每根都真能动；曲线那块的**控制点能上下拖**（双击或点「重置曲线」恢复直线）。松手后右框都会重算 |
| 5d | 到「① 转换」把模式切成「**笔刷**」再回第 ② 页 | 后两根拉条**换名**成「反射强度 / 反射染色」；环境光遮蔽那一行**藏起来**（笔刷的明暗交给 lightmap） |
| 6 | 看「其他参数」那一组 | **它一直摆在那儿**（第 2 / 3 页**没有任何"勾了才显示"的折叠组**）：粗糙度整体偏移 / 高光强度 / 金属染色强度 / 环境光遮蔽 / 曲线编辑器 |
| 7 | 看第 ③ 页的「**材质属性（必填）**」 | **常驻展开**：`$surfaceprop` 下拉（**已经有一个看得见的值**，默认 `default`，不是空的）+ 5 个常用开关 + 「自由键值」表。⚠️ 换成笔刷档（比如玻璃·窗户）时它会自动变成 `glass` |
| 7b | 把「② 预览 + 调参」的**预设下拉**从头翻一遍 | 模型路线 **11 档**；切到笔刷路线变 **10 档**（9 档笔刷 + 贴花）——**下拉会整套换**，不会把笔刷档混进模型路线 |
| 7c | 换到「**贴花**」那一档 | 「给笔刷出反射遮罩」会自动**取消勾选**（贴花不反光）；换成「玻璃·窗户」又会自动勾上 |
| 7d | 第 ③ 页「材质属性（必填）」里那个「**这个材质要透明（树叶 / 铁网 / 栅栏）**」开关 | **一直摆在那儿**（不用先勾别的才出现）。勾上 → 产出的 `.vmt` 里多一条 `$alphatest 1`（这一档若带 `$translucent` 会**被摘掉**，两个不能同时写）；产出的 `_basecolor` **保住底色自己的 alpha**（透明区域不被高光遮罩顶掉）。切到「**植被**」档它会**自动勾上**，切走**自动去掉** |
| 7e | 制造一个"要透明但没救"的情况：勾上 7d 那个开关，但**这套素材里没有法线图** | 说明列给出**人话警告**（大意：要透明就必须有法线图 → 这次**不出高光遮罩**），并且**底色 alpha 原样保留**——**不许**悄悄把透明吃掉换成不透明 |
| 7f | 另一种"白勾了"：勾上 7d 那个开关，但这套素材的**底色本来就没有透明区域** | 说明列出那句 **「这套素材的底色没有透明区域 —— 勾了也不会裁掉任何东西。」**（**不许**静默） |
| 7g | 把预设**换一档**（比如「玻璃·窗户」↔「金属」），再看第 ③ 页 | **「材质属性」整组跟着新档重放**：表面类型跟着变（`glass` ↔ `metal`）、5 个常用开关跟着这一档、要透明也跟着。⚠️ 反过来**滑杆与曲线是你的素材级微调，换档不动它们**（要拨回去点「恢复继承」） |
| 8 | 切到「**④ 导出**」，点「**开始转换**」 | 表格逐行变「完成」+**说明列列出警告**（人话）；**进度条走满**；状态栏显示「完成：成功 N / 跳过 K / 失败 M」 |
| 9 | 看「④ 导出」页的「**这次的结果**」组 | 「完成：成功 N / 跳过 K / 失败 M」+ 明细清单 + **三个按钮**：`打开输出目录`、`打开日志`、`复制失败原因`（没失败的那个是灰的） |
| 10 | 点「**打开输出目录**」 | 资源管理器打开这次产物的文件夹（PNG + `vtf\` + `.vmt` + `phong_input.json`） |
| 11 | 中途想看**取消**：点状态栏右下角的「**取消**」 | 状态栏变「正在取消…」，当前这套在**下一个阶段边界**停下并标「跳过 / 已取消」（不是立刻停，因为一次 VTFCmd 要跑一两秒）；没记进 `phong_input.json`，所以重跑会重做 |
| 12 | 再点一次「开始转换」 | 全部显示 **「跳过」**（因为指纹没变）——这是对的，不是没干活 |
| 13 | 到「**⑤ 关于**」点「打开日志」 | 打开最近一次的 `log.txt`（含参数、来源、警告） |
| 14 | 关掉程序再重新双击打开 | **语言、预设、勾选、上次的素材文件夹、窗口大小都还在** |

## 3. 特别要试的：同名冲突

如果转换的产物会和已有文件重名（比如你已经转过一次、又改了参数重转），
**应该弹出对话框问「覆盖 / 跳过」**，而不是偷偷覆盖。

⚠️ **但它不备份**：选「覆盖」就是**直接把旧文件换掉、撤不回来**（这是作者拍板的取舍：覆盖就覆盖，大不了重调材质）。
所以**别把自己手写的 `.vmt`** 放在会撞名的位置。

## 3.1 拖错文件夹 / 还没选素材就点按钮（第一次用最容易撞到）

| 你做什么 | 应该看到什么 |
|---|---|
| 拖一个**上面一级**的文件夹（里面没有 PNG） | 弹框：**「这个文件夹里没找到能认的贴图：<路径>」**，并告诉你"请选里面直接放着 PNG 的那个文件夹（Material Bakery 烘出来的那个），而不是它的上一级"；状态栏也同步说一句。**不应该看起来像什么都没发生** |
| 什么都没选就点「**开始转换**」（第 ④ 页） | 弹框「先选一个素材文件夹」，**不崩、不偷偷开始**（而且没导入素材时这个按钮本来就是**灰的**） |
| 什么都没选就点「**校验模型**」 | 弹框「先选一个编译好的 .mdl 模型」 |
| 认到素材了但**材质名是空的**就点「开始转换」 | 弹框「先填材质名（或用 .mdl 自动读）」 |
| 拖一个 **`.mdl`** 到「导入素材」的虚线框 | 自动切到「我有编译好的模型」并读出 `$cdmaterials` 与材质名（等价于点「浏览…」） |
| 第 ③ 页「自由键值」**没选任何一行**就点「**删除选中**」 | 弹框「先在上面选一行，再点「删除选中」」——**不会偷偷删掉最后一行** |

## 5. 明确"还没做"的（别当成 bug 报）

- 没有实时 3D 预览（第二版）。「一键用 HLMV 看材质」**已经做好了**（在「① 转换 → 工具路径」里）
- 「⤢ 放大预览」只放大**贴图本体**，不是带光照的 3D 渲染
- ⚠️ 预览里**拖动「高光强度」看不出变化**是正常的：它落在 `.vmt` 的 `$phongboost` 上，
  **不是贴图**。同理「反射染色」也只改 VMT。想看出变化就拖「高光锐度 / 粗糙度整体偏移 /
  金属染色强度」或改曲线
- 多套素材时预览**看的是第一套**（还没有"按表格选中项预览"）
- **一模型多套材质**：第一版一套一套跑（同一个 `$cdmaterials` 目录跑两次，材质名分别填）
- ⚠️ **第 3 页有几段很长的灰字解释显示不全**（「这些不是调效果…」/「`$surfaceprop` 决定脚步声…」/
  「要透明」那段）：它们是**一行定高**的灰字，**超长会被无声截断**（连省略号都没有）。
  这是 06 版式里"每个参数配一行解释"的既定做法；`_task/10` 只保证**新加的那句**放得下（量过宽度），
  要不要把这 3 段改成两行**等一类定**（见 `_submission/10-残留小修_20260928.md` §5-C / §6-3）
